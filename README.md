# Ubiquitous Computing – Lab 1

This repository contains three Android Studio projects completed for Lab 1.

## 1. HelloWorld
Includes:
- Hello World app
- Click Counter app

## 2. FormApp
An Android form application using LinearLayout with validation for:
- Name
- Password
- Telephone number
- Email address

Displays a toast message on successful submission.

## 3. KidsGuessGame
A number guessing game using Java and RelativeLayout.

Features:
- Random number between 1 and 30
- Higher/Lower feedback
- Guess counter
- Play Again button
